# Dynamics as Code: On Model Compression via Dynamic System

Official implementation of the paper:

**Dynamics as Code: On Model Compression via Dynamic System**

[![arXiv](https://img.shields.io/badge/arXiv-preprint-b31b1b.svg)](http://arxiv.org/abs/2610.11115)

This repository provides the implementation of our dynamic-system-based
model compression framework. The framework represents grouped neural-network
parameters using compact indices associated with states generated by dynamic systems.

The implementation includes experiments on:

- ResNet-18 / ImageNet
- Qwen2.5-1.5B
- Qwen1.5-7B

The supported mappings include space-filling/grid traversals, chaotic dynamics,
pseudo-random generators, and low-discrepancy sequences.

---

## Supported Methods

| Family                          | Method           |
| ------------------------------- | ---------------- |
| Space-filling / grid traversal  | Hilbert          |
| Space-filling / grid traversal  | Peano            |
| Space-filling / grid traversal  | Morton / Z-order |
| Space-filling / grid traversal  | Snake            |
| Chaotic dynamics                | Lorenz           |
| Congruential generator          | LCG              |
| Permuted congruential generator | PCG              |
| Low-discrepancy sequence        | Halton / QMC     |
